Finviz Snap-Nav

Two modes, one swipe gesture. Zoom mode snap-zooms around the real Finviz page. Read mode pulls pieces of the real page — a table, the chart, the news feed — into your own clean mobile layout that you build by tapping.

Works in a Safari tab — not in your “Add to Home Screen” shortcut.
A home-screen web app on iOS is a sandboxed window with no address bar and no extensions, so neither install method below can reach it. Open Finviz as a normal Safari tab (pin it under Favorites for one-tap access) to use this.
New in v2 — Read mode:
Tap the 🔄 button on the bar to flip between Zoom and Read. In Read mode, open the ⋯ menu and tap + Pick: the overlay hides, a banner appears at the top, and you tap anything on the real page to grab it. Use ⬆ Expand / ⬇ Shrink to grow or shrink the selection until it's the right chunk (a whole table instead of one cell, say), then send it to a new or existing section. Swipe left/right pages between your sections, same as zoom zones. Manage lets you rename, reorder, or delete sections.
Recommended – always on

Option A: Install via the Userscripts app

  1. Get the free Userscripts app from the App Store (by Justin Wasack) — it's a Safari extension, not a separate browser.
  2. Open Settings → Apps → Safari → Extensions → Userscripts and turn it on, allowing it on finviz.com (or “All Websites”).
  3. Open the Userscripts app itself, tap +, and paste in the script below.
  4. Save, then visit any Finviz page in Safari — the control bar appears automatically at the bottom.
No install – manual tap each visit

Option B: Bookmarklet

This version is bigger now (picker + sections), so the bookmarklet code is long. It still works as a bookmark URL — Safari stores bookmarks in a database, not an address-bar field — but if pasting feels unwieldy, Option A is much smoother.

  1. Bookmark any page first (tap Share → Add Bookmark) — this just creates an entry you'll overwrite.
  2. Go to Bookmarks, swipe the new one left → Edit.
  3. Rename it “Snap-Nav”, then tap the URL field, delete it, and paste the code below in its place.
  4. On any Finviz page, open Bookmarks and tap Snap-Nav to activate it for that page load.

Bar controls

Swipe ←/→ – next/prev zone (Zoom) or section (Read) ‹ › – same, as buttons 🔄 – switch between Zoom mode and Read mode ⋯ – opens the second row of context buttons

⋯ menu in Zoom mode

+ / − – zoom in/out around screen center Save – store current pan+zoom as a new zone Del – remove the current zone ↻ – remeasure if a zone looks clipped ⌄ – fade the bar out of the way

⋯ menu in Read mode

+ Pick – grab a piece of the real page into a section Manage – rename, reorder, delete sections ⌄ – fade the bar out of the way

While picking

Tap any element on the live page to select it. ⬆ Expand walks up to the parent container (use this if you tapped one cell but want the whole table). ⬇ Shrink walks back down. Once it's the right chunk, tap an existing section name to add to it, or + New section to name a new one. ✕ Cancel backs out without changes.

Zones and sections are remembered per page type (all stock quote pages share one set, the screener has its own), so they carry over automatically when you switch tickers.
